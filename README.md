# Node Portfolio

Personal portfolio website built with Node.js, Express, and EJS.

## Run locally

1. Install Node.js 18 or newer.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:3000`.

## Deploy on Render

- Create a **Web Service** and connect this GitHub repository.
- Runtime: **Node**
- Build Command: `npm install`
- Start Command: `npm start`
- Render provides the `PORT` environment variable automatically.

Do not upload `.env` or `node_modules/`. Keep secrets in Render's Environment settings if the app needs any.
